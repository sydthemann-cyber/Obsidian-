## 2 x 2 table + formulas

|           | case / treatment | no case / control | total             |
| --------- | ---------------- | ----------------- | ----------------- |
| exposed   | A                | B                 | a+b               |
| unexposed | C                | D                 | c+d               |
| total     | a+d              | b+d               | N = a + b + c + d |

incidence exposed: Ie
- a / (a+b)
incidence unexposed: Io 
- c / (c+d)
total incidence: It
- (a+c) / N 
risk ratio: RR
- - ( a/(a+b) )  / ( c/(c+d) ) 
prevalence ratio: PR
- ( a/(a+b) )  / ( c/(c+d) ) 
Odds ratio: OR 
- (a/c) / (b/d) = ad / bc
Attributable risk: AR
- Ie - Io 
Cumulative incidence: It 
- a + c / a + b + c + d
- a + c / PTe + PTo
- prevalence ratio = cross sectional (dont know incidence so cases are point in time) 
- risk ratio = new incident cases
